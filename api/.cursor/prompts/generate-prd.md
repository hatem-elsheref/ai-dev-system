# Generate PRD

Create a Product Requirements Document based on approved BRD and architecture direction.

## Include
- Product goals
- User journeys
- Features and priorities
- Non-functional requirements
- Release scope
- Metrics and instrumentation

## Output Format
- Product Vision
- User Personas and Jobs-to-be-Done
- User Flows
- Feature Requirements (P0/P1/P2)
- Non-Functional Requirements
- Analytics and Success Metrics
- Rollout Plan
