# Generate DB Schema

Generate MySQL schema design for project modules and APIs.

## Rules
- Normalize by domain boundaries
- Add foreign keys for integrity
- Add practical indexes for real query paths
- Plan migrations for safe evolution

## Output Format
- Entity List
- Table Definitions (columns and types)
- Keys and Constraints
- Indexing Strategy
- Migration Plan
- Query Performance Notes
- Data Retention and Soft Delete Decisions
