# Stack Rules

## Backend
- Framework: Laravel API
- Architecture: thin controllers, service-oriented domain logic
- Testing: PHPUnit feature and unit tests

## Database
- Engine: MySQL
- Design: normalized schema, proper keys/indexes, migration discipline

## Frontend
- Framework: React SPA
- UI approach: component-driven, feature-based structure, accessibility support

## Mobile
- Framework: React Native (when mobile scope exists)
- Principle: API parity with web unless intentionally documented
