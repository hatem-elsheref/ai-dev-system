# AGENTS Context

This repository is a reusable AI software factory template.

## Primary outcome
Initialize new projects with consistent architecture, docs, standards, and task decomposition before implementation.

## Default stack
- API: Laravel
- Database: MySQL
- Web: React SPA
- Mobile: React Native (optional)

## Working rule
Before coding, AI must analyze requirements, architecture impact, module boundaries, and dependencies; then generate/update docs.
