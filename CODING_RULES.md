# Coding Rules

## Core standards
- Keep code clean, readable, and easy to evolve.
- Avoid over-engineering and premature abstractions.
- Prefer small, composable, reusable modules.
- Eliminate duplication and dead code.
- Use configuration and environment values, not hardcoded constants.
- Follow `BASIC_GUIDES.md` for implementation-level conventions.

## Quality gates
- New behavior should include tests.
- Security and performance impact must be reviewed.
- Documentation must be updated for material changes.
